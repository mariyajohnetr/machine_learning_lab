## 1. Aim

To perform hierarchical clustering on the preprocessed heart disease dataset using Ward linkage and visualize the hierarchy with a dendrogram.

## 2. Dataset

## 3. Algorithm / Workflow

1. Load the dataset and remove the target.
2. Identify numerical and categorical features.
3. Standardize numerical data and one-hot encode categorical data.
4. Create the processed feature matrix.
5. Perform Ward hierarchical linkage.
6. Plot the dendrogram.
