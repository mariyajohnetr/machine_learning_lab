## 1. Aim

To implement K-Nearest Neighbour classification for heart disease prediction, compare multiple K values and select the best-performing K.

## 2. Dataset

The program loads `heart_disease_dataset.csv`. If your CSV is saved somewhere else, change this path in the program before running it.

## 3. Algorithm / Workflow

1. Load the dataset and separate features and target.
2. Identify numerical and categorical features.
3. Split the dataset with stratification.
4. Scale numerical features and encode categorical features.
5. Train KNN for the specified K values.
6. Calculate accuracy, precision, recall and F1 score.
7. Select the best K and evaluate the final model.
