## 1. Aim

To perform DBSCAN clustering on the heart disease dataset, identify clusters and noise points, and visualize the clustering result using PCA.

## 2. Dataset

The program loads `heart_disease_dataset.csv`. If your CSV is saved somewhere else, change this path in the program before running it.

## 3. Algorithm / Workflow

1. Load the dataset and separate the target.
2. Identify numerical and categorical features.
3. Scale numerical features and one-hot encode categorical features.
4. Apply DBSCAN using the notebook parameters.
5. Assign labels, identify noise points and count clusters.
6. Apply PCA for two-dimensional visualization.
