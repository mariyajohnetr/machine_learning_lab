## 1. Aim

To apply Principal Component Analysis to reduce the preprocessed heart disease feature space to two components and measure explained variance.

## 2. Dataset

## 3. Algorithm / Workflow

1. Load the dataset and separate the target.
2. Identify numerical and categorical features.
3. Scale numerical features and one-hot encode categorical features.
4. Convert the processed data when required.
5. Fit PCA with two components.
6. Transform the data and calculate explained variance.
7. Plot the two principal components.
